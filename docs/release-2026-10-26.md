## 确认的问题及最小修改

| 问题和证据 | 修改 |
| --- | --- |

| P2：原 CMake 无条件传入 GNU 参数。实际 clang-cl 片段编译警告忽略两个栈保护参数。它只证明前端参数问题，不是完整 Windows 构建。 | `CMakeLists.txt:28–105` 区分 MSVC/GNU/Clang/AppleClang；MSVC 保留 GS、SDL、CFG、DEP、ASLR，其他工具链检查可选保护参数。Linux ELF 参数限 Linux；sanitizer 默认关闭。 |

| P2：基线执行 `cmake --install` 没有安装可执行文件。 | 增加原生 install/CPack 规则和 Linux desktop/SVG 图标。CMake 下限升到 3.21，用于标准 RUNTIME_DEPENDENCIES API；没有自写依赖扫描器。 |

## 安装后实测

运行容器从 Debian 12 slim 创建，未安装 g++、CMake 或 pkg-config。
用 apt 安装真实 DEB、以 uid 1000 普通用户从 `/` 启动。
`LD_LIBRARY_PATH`、`QT_PLUGIN_PATH`、`QT_QPA_PLATFORM_PLUGIN_PATH` 均未设置。
`ldd` 无缺库；安装 ELF 没有开发 RPATH/RUNPATH；加载库和插件没有来自 `/home/gyl` 或构建目录。
ELF 检查有 BIND_NOW、GNU_RELRO、不可执行 GNU_STACK。
