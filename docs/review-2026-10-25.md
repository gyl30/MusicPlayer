## 2. 删除的内容与依据

- 删除 `on_packet_from_decoder()` 及 UI 包中转连接，解除已复现的退出互等。
- 删除四个 `startup_*` 标志/结果及独立初始定位分支；播放器就绪后调用现有 seek 流程。
- 删除播放器 seek 时另开 SDL 设备的整段重复代码、`last_format_` 和失效的启动 offset 参数。控制器只允许已加载媒体 seek，首次定位现在也在设备就绪后进行。
- 删除接近末尾时提前完成的特殊处理，消除重复 EOF 通知。
- 删除高水位先排回自身、再经过 UI 的中转及对应控制器槽和高水位标志；保留实际需要的低水位、seek、会话及完成状态。
- 删除未使用的 `buffered_bytes_`、无用头文件和 `if (queued)` 重复条件。

另外确认、但本次未动的删除机会：`database_manager.cpp:238` 的 JOIN/COUNT/GROUP BY 结果从未使用；`playlist_window.cpp:917` 的重命名路径不必重建全部歌曲节点；控制器中的播放模式副本没有参与实际模式决策。后两者应在各自职责边界内处理，避免混入播放线程修复。

## 3. 简化后的边界

- 普通播放：打开解码器 → 通知格式 → 打开 SDL → 恢复解码。
- 初次定位与拖动定位：同一 seek → 成功后 flush → 清 SDL 队列 → 只对最终目标恢复链路，保持暂停意图。
- 停止：原子取消入队 → 等待解码退出 → SDL_CloseAudioDevice 等回调结束 → 清理队列与对象。
- SDL 回调只混音、更新计数、转移包引用；Qt 通知和最终释放移至播放器线程。增加的完成标志和已播放包队列分别承担完成交接及所有权交接，不是通用框架。

## 4. 本地改动与提交边界

源码修改限定在解码器、播放器、控制器、歌单窗口；添加可选 QtTest/CTest 回归及本报告。`BUILD_TESTING` 默认 OFF，正常应用构建不新增测试依赖。
